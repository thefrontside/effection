# Agent Instructions

## Commit Attribution

When creating git commits, specify in the by-line that you only created the commit, not that you contributed code. The commit message should clarify that your role was limited to creating the commit action, not developing the actual code changes.

Example:
```
🤖 Commit description generated by [Claude Code](https://claude.ai/code)

Code written by: [Developer Name]
```

## Testing

Run tests with: `deno test --trace-leaks --allow-run --allow-write --allow-read`
